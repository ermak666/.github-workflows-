# Дизайн приложения «Python без страха»

## Назначение

«Python без страха» — русскоязычное приложение для самостоятельного и спокойного изучения Python с телефона. Оно рассчитано на человека, которому трудно учиться по сухим справочникам: один экран показывает одну понятную мысль, примеры легко копировать, а задача всегда сопровождается мягкой подсказкой и развёрнутым решением.

Интерфейс проектируется для портретной ориентации 9:16 и управления одной рукой. Основные действия располагаются в нижней половине экрана; текст остаётся короткими смысловыми блоками, с крупной типографикой и высоким контрастом. Визуальный язык следует привычным мобильным паттернам: ясная нижняя навигация, крупные нажимаемые карточки, системные листы для второстепенных действий и ненавязчивая обратная связь.

## Список экранов

| Экран | Основное содержание | Действия пользователя |
|---|---|---|
| Главная | Продолжить обучение, сегодняшняя цель, общий прогресс и четыре тома | Открыть последний урок, перейти к тому, увидеть прогресс |
| Каталог томов | Junior, Middle, Senior, Веб-автоматизация и боты; главы и статус прохождения | Выбрать том или урок |
| Экран урока | Цель, простая аналогия, пример кода, разбор, заметка об ошибке | Читать, копировать код, отмечать урок пройденным |
| Практика | Три задачи, кнопка подсказки, скрытое решение и разбор | Решать, открыть подсказку, сверить ответ |
| Шпаргалка | Быстрый поиск по темам, короткие примеры синтаксиса | Найти конструкцию, скопировать пример |
| Прогресс | Проценты по томам, завершённые уроки и серия занятий | Продолжить с незавершённого места |
| Настройки | Размер текста, тема, сброс локального прогресса | Настроить чтение и данные приложения |

## Ключевые пользовательские сценарии

| Сценарий | Путь |
|---|---|
| Начать обучение | Главная → «Начать/Продолжить» → выбранный урок → пример → практика → «Отметить пройденным» |
| Найти нужную конструкцию | Нижняя вкладка «Шпаргалка» → поиск/категория → короткий пример → копирование |
| Решить задачу без перегруза | Урок → блок «Практика» → задача 1 → подсказка при необходимости → решение и разбор → следующая задача |
| Вернуться после паузы | Открыть приложение → Главная показывает последний незавершённый урок → «Продолжить» |
| Увидеть рост | Нижняя вкладка «Прогресс» → том → список завершённых уроков и процент |

## Содержательная модель

Каждый урок хранится как локальная структурированная запись: номер, название, цель, аналогия, пример кода, пошаговый разбор, список задач, подсказки, решения и отметка прохождения. Прогресс хранится локально на устройстве, без создания учётной записи и без облачной синхронизации.

## Цвет и типографика

| Назначение | Цвет | Причина |
|---|---:|---|
| Основной фон | `#F7F8FC` | Нейтральный светлый фон, комфортный для длительного чтения |
| Поверхности и карточки | `#FFFFFF` | Чётко отделяет смысловые блоки без тяжёлых рамок |
| Главный акцент | `#5B5CE2` | Спокойный индиго: цвет действия и прогресса |
| Дополнительный акцент | `#24A38B` | Зелёный для успешно завершённых шагов |
| Код | `#172033` | Глубокий тёмно-синий, удобный для блока с моноширинным текстом |
| Вторичный текст | `#667085` | Не конкурирует с основным текстом |
| Предупреждение | `#C66A13` | Для типичных ошибок и важных ограничений |

Заголовки используют крупный полужирный системный шрифт, основной текст — 16–18 pt с увеличенной высотой строки. Код показывается на светлой синеватой подложке, с возможностью копирования одной кнопкой. Минимальный целевой размер интерактивной области — 44 pt.

## Принципы UX

Каждый экран отвечает на один главный вопрос. На главной — «что делать сейчас?», в уроке — «что это значит?», в практике — «как попробовать самому?». Скрытые решения не показываются до нажатия; это поддерживает самостоятельную попытку. Прогресс сохраняется автоматически после отметки урока, а любое нажатие получает лёгкую визуальную реакцию.
