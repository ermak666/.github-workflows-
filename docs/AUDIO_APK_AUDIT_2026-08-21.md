## Исправление

Во всех 20 проектах будет применена одна реализация: локальный MP3 сначала превращается в `Asset`, явно загружается через `downloadAsync()`, затем проигрыватель получает локальный URI. Плеер очищается при размонтировании, а сбой не подавляется молча: контекст сохраняет понятное сообщение для экрана урока и выводит техническую диагностику в консоль разработки.

## Архив APK

Предыдущий общий ZIP действительно содержал 19 ZIP-артефактов GitHub Actions, а не сами APK. Каждый внутренний ZIP содержит один `app-release.apk`. Новый пакет будет строиться из извлечённых и переименованных непосредственных `.apk` и включит 20 приложений.
