# Учебные спецификации приложений серии

Каждая строка описывает содержание отдельного приложения. Во всех курсах действуют единые правила: четыре уровня **Junior → Middle → Senior → Проекты и практика**, минимум 24 урока, 400 задач, шпаргалки, тесты, локальный прогресс и тёмная тема.

| Приложение | Junior | Middle | Senior | Проекты и практика | Безопасный тренажёр |
| --- | --- | --- | --- | --- | --- |
| Git и GitHub | снимки, статус, история | ветки и слияния | конфликты, rebase, теги | README, PR, выпуск | симулятор репозитория без доступа к файлам |
| SQL | таблицы, типы, `SELECT` | фильтры, сортировка, агрегаты | связи, индексы, транзакции | база библиотеки | изолированная база в памяти |
| HTML и CSS | теги, семантика, текст | селекторы, коробочная модель | Flexbox, Grid, адаптивность | сайт-портфолио | проверка структуры и стилей |
| JavaScript | переменные, условия, циклы | функции, массивы, объекты | DOM, промисы, модули | интерактивный список задач | ограниченный запуск без сети и файлов |
| TypeScript | простые типы, интерфейсы | функции, union, narrowing | generics, модули, `tsconfig` | типизированные заметки | проверка типов на коротких примерах |
| React | JSX, компоненты, props | state, события, формы | эффекты, маршруты, композиция | каталог привычек | визуализатор компонентов и состояния |
| Redux Toolkit | единое состояние, actions | slices, reducers, selectors | async flows, нормализация | корзина или трекер | модель store на фиксированных данных |
| Angular | компоненты, шаблоны | binding, directives, формы | сервисы, маршруты, HTTP-модель | каталог с фильтрами | конструктор структуры проекта |
| FastAPI и Django | HTTP, REST, JSON | FastAPI маршруты, схемы | Django, ORM, авторизация | API библиотеки | модель запросов и ответов без сети |

| Linux | путь, файлы, `pwd`, `ls` | права, поиск, архивы | процессы, сервисы, логи | сценарий сервера | белый список команд в симуляторе |
| Docker | образ, контейнер, порт | Dockerfile, тома, сети | Compose, healthcheck, секреты | контейнеризированный сервис | визуальная модель без запуска Docker |
| Kotlin | переменные, условия, функции | коллекции, null safety | классы, корутины, тесты | менеджер привычек | безопасный разбор кода и выражений |
| Android | Activity, Compose-экран | состояние, навигация | Room, сеть-модель, тесты | офлайн-приложение | конструктор экранов и состояний |
| C# и Unity | C# основы, классы | сцены, объекты, ввод | физика, UI, сохранение | 2D-мини-игра | модель сцены и проверка скриптов |
| Go | переменные, функции, структуры | интерфейсы, ошибки, модули | горутины, каналы, HTTP | CLI или API | разбор кода и HTTP-модели без сети |
| Rust | переменные, `match`, функции | ownership, borrowing | `Result`, traits, тесты | CLI-инструмент | визуализатор владения и заимствования |
| Моддинг игр | права, бэкап, версии | собственные 2D/3D-материалы | упаковка, совместимость, README | косметический мод-проект | чек-лист прав и симулятор совместимости |

## Правила честной практики

Кодовые курсы дают настоящий результат только для заранее указанного безопасного подмножества языка. Если пример выходит за рамки тренажёра, приложение объясняет это словами и не показывает ложный успех. Не-кодовые курсы проверяют структуру, порядок действий, итоговую конфигурацию или выбор решения.

Курс по моддингу посвящён собственным материалам и законному распространению. Он не содержит уроков о пиратстве, обходе DRM или античита, читах для сетевых игр, извлечении или публикации оригинальных ассетов Resident Evil 4 либо другой игры.
