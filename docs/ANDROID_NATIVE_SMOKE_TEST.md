# Нативная Android-проверка серии

Эта проверка выполняется на реальном Android-устройстве после успешной GitHub Actions APK-сборки. Она дополняет автоматические TypeScript-тесты, линтер, production web-экспорт и статическую проверку workflows.

| Шаг | Действие | Ожидаемый результат |
|---:|---|---|
| 1 | Установить APK любого курса серии и открыть его | Тёмный экран запуска без белой вспышки и без зависания. |
| 2 | Открыть уровень → урок → следующий урок → «Назад» → «На главную» | Все кнопки заметны, ведут в ожидаемый экран; белый экран и тупики отсутствуют. |
| 3 | Открыть мини-тренажёр и запустить безопасный разбор примера | Показано честное учебное объяснение; нет сетевых запросов, доступа к файлам или исполнения опасных действий. |
| 4 | Решить задачу и перезапустить приложение | Отметка о прогрессе остаётся сохранённой. |
| 5 | Открыть шпаргалку и увеличить размер текста | Текст не обрезан, не выходит за экран и остаётся контрастным. |
| 6 | Проверить аудио урока: слушать → пауза → продолжить → стоп | Одновременно играет только одна дорожка; «Стоп» прекращает воспроизведение. |
| 7 | Пройти короткий тест и открыть результат | Видны правильные ответы и понятное объяснение ошибки. |

Результат фиксируется как «пройдено» только если все семь шагов завершаются без блокирующей ошибки.
