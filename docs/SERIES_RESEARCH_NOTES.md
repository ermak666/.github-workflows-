# Заметки исследования для серии учебных приложений

## Фронтенд: подтверждённая последовательность

| Источник | Вывод для серии |
| --- | --- |
| [React Learn](https://react.dev/learn) | React нужно изучать после основ JavaScript: компоненты, JSX, передача данных, состояние и события составляют базу для первого приложения на React. |
| [Redux: Getting Started](https://redux.js.org/introduction/getting-started) | Redux предназначен для предсказуемого управления общим состоянием. В учебной серии его следует ставить после React и вводить через современный Redux Toolkit вместе с TypeScript. |
| [MDN JavaScript Guide](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide) | Базовый курс JavaScript должен включать типы, управление потоком, циклы, функции, коллекции, объекты, классы, промисы и модули до перехода к фреймворкам. |
| [TypeScript Documentation](https://www.typescriptlang.org/docs/) | Курс TypeScript логично строить после JavaScript: основы типов, сужение типов, функции, объекты, классы, модули, дженерики и конфигурация `tsconfig`. |
| [Angular Tutorial](https://angular.dev/tutorials/learn-angular) | Angular требует базового знакомства с HTML, CSS и JavaScript, поэтому должен идти после соответствующих основ, а не вместо них. |
| [Kotlin: Get started](https://kotlinlang.org/docs/getting-started.html) | Kotlin подходит отдельным приложением после базового программирования: можно выбрать маршрут console → тесты → Android или backend. |

Эти источники используются только как ориентиры для порядка тем. Уроки будут написаны самостоятельно, на русском и простым языком.

## Моддинг: обязательные границы курса

| Источник | Вывод для курса «Моддинг игр: с нуля до Pro» |
| --- | --- |
| [Nexus Mods: File Submission Guidelines](https://help.nexusmods.com/article/28-file-submission-guidelines) | Нельзя публиковать чужие игровые файлы, изображения или иной защищённый контент без разрешения правообладателя. Указание автора не заменяет разрешение. Нужно отдельно учить разрешениям, лицензиям и корректной атрибуции. |
| [Nexus Mods: Terms of Service](https://help.nexusmods.com/article/18-terms-of-service) | Публикация модов должна следовать правилам площадки и законодательству; учебник будет давать только легальные сценарии для одиночных игр и не будет учить пиратству, обходу защиты, читам для мультиплеера или распространению оригинальных игровых ресурсов. |

> Планируемый курс использует Resident Evil 4 (2004) и Resident Evil 4 Remake только как примеры изучения структуры мод-проекта и собственного контента. Он не будет включать инструкции по обходу DRM, античита, покупке игры, защите платформ, извлечению или распространению защищённых ассетов.
