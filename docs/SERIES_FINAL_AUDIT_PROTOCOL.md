# Финальный аудит серии «Разработка без страха»

## Когда применяется

Этот протокол выполняется только после предметного наполнения каждого отдельного приложения и до создания его финальной Android APK. Никакое приложение не считается готовым по одному лишь успешному запуску или по прохождению части тестов.

## Технический аудит

| Область | Проверка | Критерий прохождения |
|---|---|---|
| Типы | `pnpm check` | Нет ошибок TypeScript. |
| Автотесты | `pnpm test` | Все обязательные тесты прошли; пропуски документированы. |
| Стиль | `pnpm lint` | Нет ошибок линтера. |
| Production-бандл | Экспорт/production-сборка | Нет ошибок импорта, маршрутов и CSS-кэша. |
| Навигация | Главная → том → урок → практика → назад → главная | Нет белых экранов, тупиков и неверных маршрутов. |
| Локальные данные | Прогресс, закладки, недельная цель, резервная копия | Данные сохраняются и корректно восстанавливаются. |
| Учебный запуск | Предметная песочница | Показан честный учебный результат; нет доступа к сети, файлам, аккаунтам или опасным API. |
| Аудио | Слушать, пауза, продолжить, стоп, скорость | Нет наложения дорожек; действует один общий плеер. |

## Визуальный аудит

| Область | Проверка | Критерий прохождения |
|---|---|---|
| Мобильный экран | 375×812, 393×852 и 412×915 | Нет обрезанного текста, горизонтального переполнения и недоступных кнопок. |
| Тёмная тема | Основные, вторичные и ошибочные состояния | Светлый текст на тёмном фоне; нет светлых вспышек и белых карточек. |
| Контраст | Заголовки, обычный текст, кнопки, код, статусы | Все важные подписи читаются без напряжения. |
| Нажатия | Основные и вторичные действия | Целевая область не меньше 44 pt, видима реакция на нажатие. |
| Навигация | Назад, к содержанию, на главную, предыдущий/следующий урок | Кнопки заметны, понятны и ведут по безопасным прямым маршрутам. |
| Доступность | Размер текста, снижение движения, подписи действий | Макет не ломается при увеличенном тексте; отключение движения не скрывает смысл. |
| Контент | Название, примеры, задачи, шпаргалки, тесты | Нет оставшихся терминов или данных от другого предметного курса. |

## Результат аудита

Для каждого приложения создаётся короткий отчёт с датой, списком пройденных проверок, найденными проблемами, ссылками на исправления и подтверждением готовности к APK. Если хотя бы одна критическая проблема остаётся открытой, сборка APK откладывается.
