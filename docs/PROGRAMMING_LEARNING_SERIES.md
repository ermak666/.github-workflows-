# Серия «Разработка без страха»

## Идея серии

Серия состоит из небольших самостоятельных Android-приложений. Каждое отвечает на один понятный вопрос: «как писать код на этом языке или инструменте и сделать маленький проект?». Такой подход лучше, чем один гигантский учебник: знания складываются как ступеньки лестницы, а не как большая запутанная коробка с деталями.

Каждое приложение использует уже проверенный учебный контур «Python без страха»: русский язык, объяснения простыми словами, уроки с примерами, минимум три практических задачи, шпаргалки, безопасный тренажёр, офлайн-прогресс, повторение после перерыва, итоговые тесты, аудио и доступность. Учебный маршрут всегда одинаковый: **Junior → Middle → Senior → Проекты и практика**. В новой серии используется только тёмная высококонтрастная тема.

> Не нужно учить все приложения одновременно. Ученик проходит их по порядку: сначала основы и инструменты, затем веб, мобильная разработка, серверы, производительность и моддинг.

| Дорожка | Приложения | Финальный проект |

| **Python-разработчик** | Python → Git → SQL → FastAPI/Django → pytest/CI → Docker | Полезный API или бот с базой данных и надёжными тестами. |

## Очерёдность реализации

Первым нужно создавать приложение **«Git и GitHub без страха»**. Оно поможет ученику правильно сохранять код уже в Python-проектах и станет фундаментом почти для каждого следующего курса. Вторым лучше сделать **«SQL без страха»**, потому что база данных быстро делает проекты настоящими. Затем идёт веб-дорожка: HTML/CSS, JavaScript и TypeScript.

После появления основы веба можно выпускать React, Redux Toolkit и Angular по отдельности. Backend и Docker лучше строить на уже сделанных Python-проектах, а Kotlin/Android и C#/Unity — как самостоятельные прикладные ветки. «Моддинг игр» запускается после баз Git и работы с собственными 2D/3D-материалами, чтобы курс учил созданию и оформлению контента, а не опасному копированию чужих файлов.

## Границы моддинг-приложения

Курс по моддингу не учит пиратству, обходу DRM, античита, сетевым читам или извлечению и распространению оригинальных игровых ресурсов. Для Resident Evil 4 (2004) и Resident Evil 4 Remake он показывает только законный, одиночный и проектный подход: резервные копии, совместимость версий, собственные материалы, документацию, лицензии и разрешения. Правила Nexus Mods прямо запрещают загрузку защищённого контента без надлежащего разрешения, а упоминание автора не заменяет разрешение.[5]

## Статус

Сейчас создано и развивается приложение **«Python без страха»**. Следующий кандидат для полноценной реализации — **«Git и GitHub без страха»**. После него у серии появится универсальный фундамент для всех последующих языков, фреймворков и мод-проектов.
